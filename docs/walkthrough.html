What does this page prove?

Only that the visual language makes the redaction boundary easy to inspect. The events and digests are illustrative browser data; the page does not open a file, redact a stream, or certify a trace.

02 / real CLI path

Inspect first, then ask a narrow question.

Run these commands against a local JSONL file. The CLI prints deterministic counts and safe redacted matches.

agent-trace inspect events.jsonl
agent-trace query events.jsonl --type tool --contains timeout --limit 20
